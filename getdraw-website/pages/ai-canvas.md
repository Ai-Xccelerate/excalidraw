# Your canvas, now with a drawing partner

Describe what you need. Select what should change. Attach the source. getdraw.app's Canvas assistant works with the board in front of you and applies the result as editable shapes and connections.

**CTA:** Draw with AI

## It sees the work, not just the prompt

The assistant receives a structured view of the current board: object types, labels, positions, dimensions, colors, and connections. With objects selected, it focuses on that part of the diagram. With nothing selected, it can work across the board.

Manual edits remain part of the next turn, so the conversation follows the drawing as it changes.

## From request to canvas action

Ask the assistant to:

- Create a flowchart, architecture map, decision tree, or process.
- Add or connect new steps.
- Rename shapes and arrow labels.
- Recolor states or categories.
- Remove obsolete objects.
- Organize a complex flow into titled stages or lanes.
- Work from an attached image, Markdown brief, CSV, JSON, YAML, log, or other supported text file.

Each completed turn reports what it drew, connected, changed, or removed. New objects are selected and brought into view so you can continue immediately.

## Designed for readable diagrams

The assistant uses conventional visual grammar: start/end states, actions, decisions, labeled branches, restrained category colors, and clear connection routing. For larger flows, it can group nodes into named lanes instead of stretching everything into one unreadable chain.

The output is still yours. Move it, restyle it, rewrite it, undo it, or ask for another pass.

## More than one way to generate

### Text to diagram

Describe a diagram, refine the generated Mermaid in chat, preview it, and insert it into the canvas.

### Mermaid to canvas

Bring known Mermaid source directly into the editor and keep supported results editable.

### Wireframe to HTML

Sketch an interface, select the relevant region, and generate an HTML starting point for review and production hardening.

### MCP for external agents

Approve a compatible AI client to create drawings in your account. Agent-created diagrams use your saved defaults and arrive with a direct link.

## Practical control

- AI requires a signed-in account and a configured service.
- Daily allowances prevent unbounded use and are surfaced in the generation experience.
- Select objects to narrow the assistant's scope.
- Undo applied canvas actions like any other edit.
- Disconnect external agent clients from Settings.
- Review generated code before production use.
