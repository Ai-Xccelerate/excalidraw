# Everything your visual work needs to keep moving

getdraw.app pairs a fast infinite canvas with saved organization, live teamwork, and AI that works with editable objects—not just pixels.

**CTA:** Open the canvas

## A canvas that feels immediate

- Infinite space for diagrams, workshops, wireframes, and notes
- Rectangles, ellipses, diamonds, sticky notes, text, images, free drawing, frames, lines, and arrows
- Connector handles that create bound arrows from any side of a selected shape
- Straight, curved, and elbow connections with labels and multiple arrowheads
- Reliable whole-shape selection, grouping, alignment, distribution, layering, locking, and rotation
- Mouse controls with wheel zoom and right-drag panning
- Trackpad controls with two-finger panning and pinch zoom
- Automatic device detection when you switch between input methods
- Light, dark, and focused Zen modes
- Search and command palette for large canvases and keyboard-first work

## Draw your way

Style strokes, fills, fonts, corners, colors, opacity, and roughness. Set account-level drawing defaults once, then use them for new manual objects and agent-generated diagrams.

The built-in library provides reusable visual components, including a curated starting set for AI architecture, agentic workflows, cloud infrastructure, and AI infrastructure. Add your own grouped objects to a personal library and carry them from board to board.

## Move from idea to structure with AI

The Canvas assistant can create a new diagram, extend an existing one, work on selected objects, and apply changes directly to the board. Attach an image or supported text file, dictate a prompt in compatible browsers, and refine the work in conversation.

Text to diagram turns a description into previewable Mermaid. The Mermaid toolbar inserts supported diagram definitions into the canvas. Wireframe to code turns a selected visual sketch into an HTML starting point for further engineering review.

## Keep drawings findable

Every account drawing gets a title, thumbnail, role, and modified time. Search, filter, sort, choose grid or list view, and group drawings into collections. When shared workspaces are available, switch context without mixing personal and team work.

Deleting is a reversible first step: owned drawings remain in Trash for 90 days unless you permanently remove them sooner.

## Share for participation or presentation

Start live collaboration for co-editing, participant presence, invitations, and QR-code handoff. Or export a separate read-only snapshot when the recipient should see a fixed result without signing in.

Portable `.excalidraw` files, PNG, SVG, clipboard export, and optional embedded scene data support handoff beyond the app.

## Bring outside agents into the workflow

getdraw.app speaks MCP. After sign-in and explicit approval, a compatible AI client can list your owned drawings, read limited drawing details, inspect your visual defaults, and create empty drawings, structured flowcharts, or supported Mermaid flowcharts. Connected clients remain visible and revocable in Settings.
