# Turn ideas into editable diagrams

Draw by hand, build with AI, and shape the result with your team. getdraw.app brings diagrams, whiteboards, wireframes, live collaboration, and an AI canvas assistant into one visual workspace.

## One canvas. Three ways to move the work forward.

### Draw it

Sketch freely or build with shapes, sticky notes, text, images, frames, and connectors. Switch between mouse and trackpad controls, use light or dark mode, and keep every object editable.

**Link:** Explore the canvas

### Ask for it

Tell the Canvas assistant what you want to show. It can read the board, focus on selected objects, use images or text files as context, and create or revise the diagram in place.

**Link:** Meet the AI canvas

### Build it together

Start a live session, invite teammates, share the room from any device with a link or QR code, and watch the canvas update as the team works.

**Link:** See team collaboration

## AI output you can keep working with

Most AI image tools stop at the picture. getdraw.app creates diagram elements: labeled shapes, attached arrows, decision branches, and organized lanes. Move a box. Rewrite a label. Change the route. Keep going.

### From a conversation

Ask for a flowchart, architecture map, process, or decision tree. Refine it with follow-up instructions and manual edits.

### From Mermaid

Paste existing Mermaid or generate it from a prompt, preview the result, and insert supported diagrams into the canvas.

### From your AI agent

Connect a compatible MCP client and let an approved agent create a saved drawing in your account—using your drawing preferences.

## The visual workspace behind the canvas

A useful whiteboard has to be easy to return to.

- Search drawings by name.
- Filter owned, shared, and unfiled work.
- Sort by date or title.
- Switch between visual grid and detailed list views.
- Organize drawings into collections.
- Move between personal and shared workspace scopes.
- Recover deleted drawings from Trash for 90 days.

## Share the right version

### Work live

Use a collaboration room when people need to edit together. Drawing roles keep owners, editors, and viewers distinct.

### Send a snapshot

Export an encrypted, read-only link when someone only needs to see the result. It opens without an account and stays separate from the original drawing.

### Take it anywhere

Export portable drawing files, PNG, or SVG. Embed scene data in supported image exports when you need an editable path back.
