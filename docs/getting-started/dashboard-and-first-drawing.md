# Dashboard and your first drawing

After sign-in, the dashboard is home base for drawings, collections, workspaces, Trash, and account settings.

## Create your first drawing

1. Select **Start drawing** in the upper-right corner.
2. The app creates an **Untitled** drawing and opens the canvas.
3. Select the title at the top of the editor to rename it.
4. Choose a tool from the top toolbar and begin drawing.

Changes to a signed-in drawing are saved automatically. The dashboard thumbnail and modified time update from saved canvas activity.

If you create a drawing while viewing a collection, the new drawing begins in that collection. If a shared workspace is selected, the drawing is created in that workspace.

## Open an existing drawing

Select a drawing thumbnail or title. Use the folder button in the editor to browse other drawings without first returning to the dashboard. The in-editor list follows the current personal or shared workspace and shows each drawing's access role.

## Find and view drawings

The dashboard toolbar supports:

- **Search drawings** by title.
- **Filter** by all drawings, owned by you, shared with you, or not in a collection.
- **Sort** by last modified, oldest first, name A–Z, or name Z–A.
- Switch between **grid view** and **list view**. The browser remembers the selected view and sort order.

List view also shows a drawing's collection, your role, and its last-modified time.

## Drawing actions

Open the three-dot menu on a drawing you can edit to:

- Rename it.
- Move it to a collection or back to **No collection**.
- Move it to Trash, if you are the owner.

You can also drag a drawing card or row onto a collection in the sidebar. Viewers can open drawings but do not receive editing or filing actions.

## Personal and shared scopes

The workspace selector is shown when at least one shared workspace is available. Select **Personal** for your own drawing area or select a workspace to see its drawings and collections. The app remembers the selection on that browser.

Drawings shared directly with you can appear in a separate **Shared with you** section when they are outside the workspace currently selected.

## Return to the dashboard

From the editor, select the getdraw logo, open the main menu and choose **Dashboard**, or open the drawings sidebar and choose **Dashboard**.
