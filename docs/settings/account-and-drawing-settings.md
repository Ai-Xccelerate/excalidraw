# Account and drawing settings

Open the dashboard and select the gear icon. Settings are grouped into Profile, Password, Notifications, Drawing defaults, and Agents & MCP.

## Profile

Set a display name for shared drawings and live collaboration. The account email is shown for reference and cannot be edited in this version. Its verification status appears below the field.

## Password

Enter the current password and a new password of at least eight characters. After the change:

- The current browser receives a replacement session and stays signed in.
- Older application sessions are invalidated.
- Existing OAuth/MCP agent connections continue until separately disconnected.

## Notifications

The app stores preferences for:

- Collaboration invitations
- Mentions
- Security alerts
- Product updates
- Weekly digest

These controls record what you want to receive. Availability of each email depends on the corresponding product notification workflow; the settings screen itself is not proof that every message type is active in every deployment.

## Drawing defaults

Defaults apply to new objects you draw and to diagrams created for you through MCP. Existing canvas objects are not automatically restyled.

You can set:

- Font: hand-drawn, normal, or code
- Font size: small through extra large
- Stroke width and style
- Hand-drawn sloppiness level
- Sharp or round corners
- Straight, curved, or elbow arrows
- Stroke color
- Default agent-generated node shape

Additional default fields for background color and fill style are stored by the service and used by the editor/diagram builder, although this version of the settings screen does not present separate controls for them.
