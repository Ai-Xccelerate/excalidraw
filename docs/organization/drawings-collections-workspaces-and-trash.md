# Drawings, collections, workspaces, and Trash

## Drawings

A drawing is a saved, editable canvas. Each drawing has a title, thumbnail, last-modified time, location, and access role. Create drawings from the dashboard or from **New drawing** in the editor menu.

Owners and editors can rename and edit a drawing. Only its owner can move it to Trash or manage drawing invitations.

## Collections

Collections organize drawings inside the current personal or shared workspace.

To create one:

1. Select the plus button beside **Collections**.
2. Enter a collection name.
3. Press Enter or click away to save it.

To file a drawing, drag its card or list row onto a collection, or use the drawing's three-dot menu and choose **Move to**. Drop a drawing on **All drawings** or choose **No collection** to remove it from a collection.

Use the pencil control beside a collection to rename it and the trash control to delete it. Deleting a collection does not delete its drawings; their collection assignment is cleared.

## Workspaces

Every account has a personal workspace. Shared workspaces appear in the workspace selector when your account has membership in them. Selecting a workspace changes the drawings and collections shown and determines where a new drawing is created.

Current end-user UI supports switching among available workspaces. Workspace creation and workspace-member administration are service capabilities but are not exposed as dashboard controls in this version. Direct drawing invitations are available from the live-collaboration dialog.

Members of a shared workspace can edit drawings in that workspace. A drawing shared directly with you outside the current workspace can appear under **Shared with you**.

## Trash

Deleting an owned drawing moves it to Trash instead of erasing it immediately.

- The complete drawing remains restorable for 90 days.
- The Trash card shows the deletion time and remaining retention.
- Select **Restore** to return it to active drawings.
- Select **Delete forever** to permanently remove one drawing.
- Select **Empty trash** to permanently remove everything in Trash.
- Expired items are purged automatically.

A drawing in Trash cannot be opened, edited, or joined through live collaboration. If its old collection no longer exists when restored, it returns to **All drawings**.

Only owners see their deleted drawings and can restore or permanently delete them. Permanent deletion cannot be undone.
