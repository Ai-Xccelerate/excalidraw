# Keyboard shortcuts and gestures

Open **Help** in the editor for the authoritative shortcut list for your operating system. `Cmd` on macOS generally corresponds to `Ctrl` on Windows and Linux.

## Common editing

- `Cmd/Ctrl + Z`: undo
- `Cmd/Ctrl + Shift + Z` or `Cmd/Ctrl + Y`: redo
- `Cmd/Ctrl + C`, `X`, `V`: copy, cut, paste
- `Cmd/Ctrl + D`: duplicate selection
- `Delete` or `Backspace`: delete selection
- `Cmd/Ctrl + A`: select all
- `Escape`: leave editing, close a dialog, or clear selection depending on context
- `Enter`: edit selected text or a shape label
- `Cmd/Ctrl + K`: add or edit a link on the selected object

## Canvas gestures

- Mouse mode: wheel to zoom; right-drag to pan; right-click without dragging for the context menu.
- Trackpad mode: two-finger scroll to pan; pinch to zoom.
- Any mode: Space-drag, middle-button drag, or the Hand tool to pan.
- Shift while resizing preserves proportions.
- Alt/Option while resizing works from the center where supported.
- Shift while rotating constrains the angle.
- Shift-click adds or removes an object from the current selection.

## Text and lines

- Double-click a shape to add or edit its label.
- Double-click a line or arrow to edit its points.
- Enter or `Cmd/Ctrl + Enter` finishes text editing depending on the active editor state; use the hint shown below the canvas.
- Shift+Enter adds a new line in the Canvas assistant instead of sending.

The editor's Help dialog also lists shortcuts for deep selection, flowchart navigation, locking, cropping images, zoom-to-fit, and moving around large canvases.
