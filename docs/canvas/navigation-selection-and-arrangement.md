# Navigation, selection, and arrangement

## Choose an input mode

The lower-left **Auto / Mouse / Trackpad** control changes canvas navigation:

- **Auto** detects the device for each gesture.
- **Mouse** makes the wheel zoom and right-drag pan.
- **Trackpad** makes two-finger scrolling pan and pinch gestures zoom.

Use a fixed mode if automatic detection feels wrong for your hardware.

## Pan and zoom

- In Mouse mode, scroll the wheel to zoom and right-drag to pan. A right-click without dragging still opens the context menu.
- In Trackpad mode, two-finger scroll pans and pinch zooms.
- The Hand tool, Space-drag, middle-button drag, and touch gestures provide additional ways to pan.
- Use the lower-right zoom controls to zoom in, zoom out, or reset the zoom.
- Open Help for **Zoom to fit all elements** and **Zoom to selection** shortcuts.

## Select objects

- Click an object to select it.
- Shift-click to add or remove objects from the current selection.
- Drag a selection box around objects.
- Use the selection preference to choose containment or overlap box selection.
- Use lasso selection for an irregular group.
- Use deep selection to reach an object inside a group or overlapping stack.

When the Canvas assistant is open, selecting objects before sending a request limits the assistant's working context to those objects.

## Arrange a diagram

With multiple objects selected, use the actions menu to:

- Align edges or centers.
- Distribute objects horizontally or vertically.
- Group and ungroup.
- Bring forward, send backward, bring to front, or send to back.
- Flip horizontally or vertically.
- Lock or unlock the selection.

Frames provide named visual regions and can contain related objects. Agent-created flowcharts may use titled lane-like frames to group stages or systems.

## Work with arrows and flowcharts

Double-click a line or arrow to edit its points. Bound arrows follow their connected shapes. You can disable binding temporarily with the modifier shown in Help, or bind to a fixed point when the route must land on a specific side.

## Find content on a large canvas

Choose **Find on canvas** from the main menu to search text and frames. Select a result to navigate to it. The command palette also provides keyboard-first access to editor actions.
