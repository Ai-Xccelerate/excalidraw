# Editor basics

The editor is an infinite canvas for diagrams, whiteboards, wireframes, notes, images, and visual thinking.

## The editor layout

- The getdraw logo returns to the dashboard.
- The drawing title at the top can be selected to rename the drawing.
- The top toolbar contains selection, shapes, arrows, free drawing, text, images, frames, sticky notes, laser pointer, and Mermaid tools.
- The sparkle button opens the **Canvas assistant** on desktop.
- The share/collaboration control opens live collaboration and read-only sharing.
- The folder button opens your recent drawings for the current workspace.
- The lower-left area contains undo, redo, and input-device controls.
- The lower-right area contains zoom, theme, and help controls.
- The main menu contains file, export, search, command palette, preferences, language, canvas background, dashboard, and drawing actions.

## Draw and edit

1. Choose a toolbar tool.
2. Click and drag on the canvas. For text, click and type. For a sticky note, a single click drops a ready-sized note.
3. Return to **Selection** to move, resize, rotate, style, group, or delete objects.
4. Use undo and redo whenever needed.

Most tools return to Selection after one use. Toggle the toolbar lock when you want to create several objects of the same kind.

## Styling

When an object is selected, the properties panel can change settings relevant to that object, including:

- Stroke and background colors
- Fill pattern
- Stroke width and style
- Opacity and hand-drawn roughness
- Corners and arrow type
- Font, size, and alignment
- Arrowheads at either end

Account-level drawing defaults affect newly created objects on every canvas. They do not restyle existing objects. See [Account and drawing settings](../settings/account-and-drawing-settings.md).

## Rename a drawing

Select the drawing title at the top of the canvas, enter the new name, and press Enter or click away. Renaming in the editor and renaming on the dashboard update the same saved title.

## Save behavior

Drawings opened from a `/d/...` address save changes to the signed-in account automatically. Avoid closing the tab immediately after a large edit if the app is still showing a save or connection warning.

For an additional portable copy, use **Save to file**. This downloads scene data that can be reopened later. Image exports are useful for viewing and presentation but are not always a complete editable backup unless scene embedding is enabled.

## Light, dark, and focused modes

Use the theme control or main menu for light, dark, or system appearance. **Zen mode** hides most interface controls for a focused canvas; use its exit control or the documented shortcut to leave it.
