# Shapes, sticky notes, text, and connectors

## Core tools

The main toolbar includes:

- Rectangle, diamond, and ellipse
- Sticky note
- Arrow and line
- Free draw
- Text
- Image
- Eraser
- Frame
- Laser pointer
- Selection and lasso selection
- Mermaid to editable diagram

Additional tools include web embeds and other generation features when available.

## Sticky notes

Choose **Sticky note** or press `N`.

- Click once to place a standard note, then type.
- Drag to choose a custom note size.
- Notes use solid paper-like colors and retain normal rectangle behavior.
- You can bind arrows to a note, resize it, export it, and edit its text like other labeled shapes.

## Add and edit text

- Choose **Text** or press `T`, then click and type.
- Double-click a shape to add or edit its bound label.
- Double-click existing text, or select it and press Enter, to edit it.
- Use the text properties to change font, size, alignment, and color.
- Bound text moves with its shape and the container grows or wraps as needed.

## Connect shapes quickly

Select one unlocked rectangle, ellipse, diamond, or sticky note. Four connector dots appear around it. Drag a dot toward another shape to create a bound arrow.

Bound arrows stay attached when either shape moves or resizes. This makes connector handles the fastest way to extend a flowchart. You can still use the Arrow tool directly for multi-point, curved, elbow, or unbound arrows.

For a decision node, label outgoing arrows—for example, **Yes** and **No**—so the diagram remains understandable without narration.

## Select shapes reliably

Filled and hollow shapes can be selected from anywhere inside their outline, not only by clicking the border. This also makes it easier to add centered bound text.

## Resize and rotate

Select an object and drag its resize handles. The rotation handle sits outside the upper-left corner so it stays distinct from the resize handles. Hold Shift while rotating to constrain angles. Locked elements cannot be moved, resized, rotated, or used to start a connector drag until unlocked.

## Arrow types

- **Straight** for direct relationships
- **Curved** for softer routes or parallel relationships
- **Elbow** for orthogonal diagrams and clean architecture flows

Arrow bindings, fixed points, labels, start/end arrowheads, and line-point editing remain available after creation.
